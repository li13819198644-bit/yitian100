# 词性与释义更新

2026-10-14：在最新 main 的五个词性词条与每日 15 个旧词减负规则上扩展。保留原词 ID、词源资料、学习进度、个人设置及自选加练功能。

## 展示与范围

- 605 个内置词按当前学习义标注主要词性；68 个多词性词单独配对常用释义。词性按人工列出的明确词表查找，不从字尾推测。
- concrete 默认答案分开显示形容词“具体的、明确的；实在的”和不可数名词“混凝土”，分别给 concrete evidence 与 pour concrete 的搭配。保留已有用混凝土铺设的动词释义及例句，放在详情的可选“其他用法”中，不让较少用含义占据快速评分页。
- abstract 的抽象／摘要、variable 的变量／可变、function 的功能／运作、sanction 的批准／制裁等常用语义分开。permit、refund、attribute、moderate 等的读音与对应词性一起显示，避免一条音标代表不同读音。
- 未揭示的词卡仍只显示英文；揭示后直接给词性和释义，维持会／不会。列表、详情、复盘说明与报告使用同一份词义信息。
- `senses` 为可选字段。兼容 main 既有中文词性、例句和译文，也支持新词性编码、搭配与提示。旧 JSON／CSV 无需增加字段；未知自定义词不强行猜词性。
- 本次内容是常用义选录，不声称覆盖每个词的全部专业、罕用或历史词义。原有五条 Cambridge 词义资料优先于扩充表，保留核对后的译文与语法限定。

## 资料与核对边界

读取 [Open English WordNet](https://github.com/globalwordnet/english-wordnet/tree/bff3181fe5c810dcd157cba0eed60322a6e0aaed/src/yaml) 的 26 个英语词条文件，按 lemma 核对词性，不根据汉语词尾机械分类。602 个内置词在数据中匹配，当前学习义的名词／动词／形容词／副词标注均与已记录词性相容。roadmap、whereas、whereby 在此次抽取中没有匹配；其名词、连词、副词用法按通常用法人工标注。

WordNet 是核对线索，不覆盖所有语法类别和现代商业语义；不把缺失记录视为该用法不存在。中文释义、搭配译文及学习义的选择为人工整理。先前 main 中五个词的 Cambridge 来源链接继续保留，本次没有重新读取这五条外部词典网页。

## 文件与回归

- `types.ts`：可选结构化义项、读音、搭配、例句、译文与较少用标记。
- `data/studyWordSenses.ts`：605 个当前学习义的词性及 68 个多词性条目；`data/wordSenses.ts` 保留先前核对的五个词及来源。
- `lib/wordSenses.ts`：新旧词性标签、词义回退、报告格式及导入验证。
- `WordMeanings.tsx`：词性与义项逐行配对，显示相应读音；`WordMeaning.tsx` 兼容先前组件接口。
- `WordRecallCard.tsx`、`App.tsx`：揭示式答案、详情、列表与完整报告接入；`dailyReport.ts` 同步导出义项。
- `seedWords.ts`、`generatedBatch7.ts`：更新 concrete 的文本与结构化义项，沿用本机词库初始化刷新内容。
- `importer.ts`：兼容旧格式，保留已有义项中的双语例句，拒绝非法新词性数据。
- `relief.ts`：合并两套功能后，浏览词义的时间标记不占用当天 15 个旧词的练习额度。
